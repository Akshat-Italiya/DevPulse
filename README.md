# DevPulse - Developer Productivity & Agent Hub

DevPulse is a full-featured developer productivity dashboard built with **React 18**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ VS Code Power Features Configured

- **Debug in Chrome (`.vscode/launch.json`)**: Press `F5` to start debugging directly from VS Code with live breakpoints in React components.
- **One-Click Build Task (`.vscode/tasks.json`)**: Press `Cmd+Shift+B` to run the TypeScript build check.
- **Recommended Extensions (`.vscode/extensions.json`)**: Auto-prompts for Tailwind CSS, ESLint, Prettier, and React Snippets.
- **Auto Format & Lint (`.vscode/settings.json`)**: Automatically formats code on save with Prettier and runs ESLint fixes.

---

## 🤖 Antigravity Mastery

- **Project Rules (`.agent/rules/coding-standards.md`)**: Configured so the agent adheres to clean TypeScript and Tailwind conventions throughout development.
- **Interactive Planning**: Use `/plan` to map out features before writing code.
